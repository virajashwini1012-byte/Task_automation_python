# ⚙️ Automated Transaction Report Generator

A Python-based automation project developed as part of the **CodeAlpha Python Programming Internship**.

The application reads transaction data from a CSV file, automatically processes the data, calculates transaction statistics, displays the results, and generates a detailed text report.

---

## 🎯 Project Objective

The objective of this project is to demonstrate how Python can be used to automate repetitive data-processing tasks.

The application automatically:

- Reads transaction records from a CSV file
- Processes transaction information
- Calculates total transaction count
- Counts successful and failed transactions
- Calculates total transaction amount
- Calculates successful and failed amounts
- Calculates transaction success rate
- Generates an automated report
